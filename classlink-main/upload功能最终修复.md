## 技术实现

### 后端API (`http://127.0.0.1:8000`)
- `/api/analyze-paper` - 上传试卷
- `/api/ai-hint` - AI提示服务
- 支持多格式文件处理

### 前端上传流程
```
用户选择文件 → 读取文件数据 → 确定MIME类型
    ↓
创建multipart请求 → 发送到后端 → 处理响应
    ↓
成功: 显示题目数量 → 保存数据
失败: 显示错误信息 → 重试
```

### 错误处理机制
1. **网络错误**: 显示HTTP状态码
2. **文件错误**: 显示具体错误信息
3. **服务器错误**: 显示后端返回的消息
4. **未知错误**: 显示异常信息
