## 技术实现

### 1. 后端文件处理流程
```
接收上传文件 → 检查文件格式 → 根据格式调用不同处理函数
    ↓
图片文件 → AI分析 → 提取题目
    ↓
文档文件 → 保存临时文件 → 返回模拟数据（可扩展）
    ↓
文本文件 → 解析文本 → 提取题目
```

### 2. 前端上传流程
```
用户点击上传 → 文件选择器弹出 → 选择文件
    ↓
读取文件数据 → 确定MIME类型 → 创建multipart请求
    ↓
发送到后端 → 处理响应 → 显示结果
```

### 3. 错误处理机制
- **前端**: 捕获异常，显示用户友好的错误信息
- **后端**: 详细的错误日志，返回结构化的错误响应
- **网络**: 超时处理和重试机制

## 使用说明

### 1. 上传文件
1. 点击右上角上传按钮
2. 选择"上传文件"
3. 选择支持的格式文件（图片、PDF、Word、文本）
4. 等待上传完成

### 2. 拍照上传
1. 点击右上角上传按钮
2. 选择"拍照上传"
3. 使用相机拍照
4. 确认并上传

### 3. 查看结果
- **成功**: 绿色提示框显示题目数量
- **失败**: 红色提示框显示错误原因
- **状态**: 顶部进度条显示上传状态
